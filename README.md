# اسأل ملف قطاع العمل

مشروع تعليمي للإجابة عن الأسئلة بالعربية اعتمادًا على بيانات قطاع العمل، مع عرض المصادر وأرقام الصفحات.

## مشاهدة المشروع ونتائجه

افتح [دفتر المشروع](Arabic_RAG_Colab.ipynb) لمشاهدة الخلايا والإجابات والجداول المحفوظة مباشرة في GitHub.

النتائج مأخوذة من جلسة كولاب بتاريخ ٢٣ سبتمبر ٢٠٢٦. حُوّلت النتائج المحفوظة داخل العناصر التفاعلية إلى مخرجات ثابتة حتى تظهر في معاينة GitHub، دون إعادة تشغيل النموذج أو تغيير الإجابات. بقيت الخلايا البرمجية وأرقام تنفيذها كما هي، وتوجد [النسخة الأصلية المحفوظة](Arabic_RAG_Colab_Original.ipynb) للمراجعة.

GitHub يعرض النتائج المحفوظة. لتجربة أسئلة جديدة، افتح الدفتر في كولاب وشغّل خلاياه بالترتيب؛ عندها تظهر أزرار الأسئلة والتقييم مجددًا.

## التشغيل في كولاب

[افتح الدفتر في كولاب](https://colab.research.google.com/github/Ahmed8M/arabic_rag/blob/main/Arabic_RAG_Colab.ipynb)

١. ارفع ملفات المشروع إلى المجلد `Colab Notebooks/Arabic_RAG_Colab` في Google Drive.

٢. افتح `Arabic_RAG_Colab.ipynb` في كولاب، وفعّل معالج الرسوميات إن توفر.

٣. شغّل الخلايا بالترتيب، واسمح بربط Drive، ثم انتظر تنزيل النماذج وتجهيز البيانات.

٤. اكتب سؤالك واضغط **أجب**. تعمل الاختبارات المطولة بأزرار منفصلة.

## طريقة العمل

يقرأ المشروع الملف ويقسّمه إلى مقاطع، ثم يبحث عن المقاطع الأقرب للسؤال ويعيد ترتيبها. يقرأ نموذج الإجابة المقطع المختار ويولّد إجابة بالعربية، وتُعرض المصادر للمراجعة.

النماذج تعمل داخل جلسة كولاب دون مفتاح أو واجهة برمجية للتوليد:

- البحث: `intfloat/multilingual-e5-small`
- إعادة الترتيب: `cross-encoder/mmarco-mMiniLMv2-L12-H384-v1`
- الإجابة: `Qwen/Qwen2.5-1.5B-Instruct`

## الملفات

| الملف | المحتوى |
| --- | --- |
| `Arabic_RAG_Colab.ipynb` | الدفتر مع مخرجات ثابتة ظاهرة |
| `labor_2026.md` | بيانات قطاع العمل |
| `evaluation.json` | أسئلة الاختبار ومراجع التقييم؛ لا تُستخدم لتوليد الإجابات |
| `colab_evaluation_results.json` | نتائج آخر اختبار كامل في كولاب |
| `baseline_results.json` | نتائج تشغيل سابق للمقارنة |
| `Arabic_RAG_Colab_Original.ipynb` | النسخة الأصلية كما حُفظت في كولاب |

يتضمن التقييم مقارنة البحث قبل إعادة الترتيب وبعدها، وتقييمًا حسب الشرائح، وتحليل الأخطاء، وتقريرًا نهائيًا. أحكام المراجعة البشرية في الجلسة المحفوظة ما زالت «لم يُراجع»؛ مقاييس البحث لا تعني أن جميع الإجابات صحيحة.

البيانات مؤرخة في يونيو ٢٠٢٦. راجع المصادر المعروضة للتحقق من الإجابات.
